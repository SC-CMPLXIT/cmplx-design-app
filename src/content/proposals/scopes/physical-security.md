## SCOPE OF SERVICES

**Physical Security Systems**

Access Control & Video Surveillance

## 1. Executive Summary

This document defines the scope of services for the design, installation, configuration, and maintenance of physical security systems including access control and video surveillance. The systems will provide comprehensive security coverage, monitoring capabilities, and controlled access to designated areas while ensuring compliance with industry standards and regulatory requirements.

## 2. Project Overview

### 2.1 Objectives

- Implement integrated access control and video surveillance systems
- Enhance facility security through centralized monitoring and management
- Provide real-time alerting and incident response capabilities
- Ensure compliance with regulatory and organizational security policies
- Enable audit trails and forensic investigation capabilities

### 2.2 Deliverables

- Complete system design documentation
- Installed and configured access control hardware and software
- Installed and configured video surveillance system
- System integration and testing documentation
- User training materials and sessions
- As-built documentation and warranties
- Ongoing maintenance and support services

## 3. Access Control System Services

### 3.1 System Design and Planning

- Site survey and security assessment
- Door and access point identification
- Security zone definition and classification
- Access control topology design
- Network infrastructure requirements analysis
- System architecture and integration planning

### 3.2 Hardware Installation

- Card readers and biometric devices installation
- Door controllers and interface modules mounting
- Electric locks, magnetic locks, and door strikes installation
- Request-to-exit devices and door position sensors
- Power supply units and battery backup systems
- Network switches and cabling infrastructure

### 3.3 Software Configuration

- Access control management software installation
- Database setup and configuration
- User and cardholder database creation
- Access levels and schedules configuration
- Anti-passback and duress alarm setup
- Integration with video surveillance and alarm systems
- Reporting and audit trail configuration

### 3.4 Credential Management

- Credential encoding system setup
- Card and badge printing equipment configuration
- Biometric enrollment procedures
- Mobile credential deployment (if applicable)
- Visitor management system integration

## 4. Video Surveillance System Services

### 4.1 System Design and Planning

- Coverage analysis and camera placement planning
- Field of view calculations and lens selection
- Lighting assessment and supplemental lighting design
- Storage capacity requirements and retention policy design
- Network bandwidth analysis and optimization
- Video management system architecture design

### 4.2 Camera Installation

- IP camera procurement and installation (fixed, PTZ, and specialty cameras)
- Camera mounting hardware and weatherproof housings
- Cable installation (Cat6, fiber optic, or coaxial as required)
- Power over Ethernet (PoE) switches and injectors
- Camera aiming, focusing, and image optimization

### 4.3 Recording and Storage Infrastructure

- Network Video Recorder (NVR) or Video Management System (VMS) installation
- Storage array configuration (RAID, hot-swap capabilities)
- Backup and redundancy system setup
- Recording schedules and retention policies configuration
- Archive and export capabilities setup

### 4.4 Video Analytics and Intelligence

- Motion detection configuration
- Object detection and classification setup
- Perimeter intrusion detection
- License plate recognition (LPR) system integration
- Facial recognition capabilities (if required)
- Alert and notification rules configuration

### 4.5 Monitoring and Display

- Control room workstation setup
- Video wall installation and configuration
- Multi-monitor display configuration
- Remote viewing and mobile application setup
- User interface customization and view layouts

## 5. System Integration Services

### 5.1 Platform Integration

- Access control and video surveillance system integration
- Integration with intrusion detection systems
- Building management system (BMS) integration
- Fire alarm system integration
- Enterprise resource planning (ERP) or HR system integration

### 5.2 Event Management

- Unified event correlation and management
- Automated incident response workflows
- Video bookmarking on access control events
- Cross-system alerting and notification

## 6. Testing and Commissioning

- Component-level functional testing
- System integration testing
- Performance and load testing
- Failover and redundancy testing
- Network security and penetration testing
- User acceptance testing (UAT)
- System commissioning and final acceptance

## 7. Training Services

### 7.1 Administrator Training

- System administration and configuration
- User and credential management
- Database management and backup procedures
- Report generation and audit procedures
- Troubleshooting and basic maintenance

### 7.2 Operator Training

- Daily operations and monitoring procedures
- Event response protocols
- Video search and retrieval
- Emergency lockdown and unlock procedures
- Incident documentation

### 7.3 Training Materials

- Comprehensive user manuals
- Quick reference guides
- Video tutorials
- Standard operating procedures (SOPs)

## 8. Documentation Deliverables

- System design documentation and specifications
- Network topology diagrams
- Floor plans with device locations
- As-built drawings and cable schedules
- Equipment inventory and asset list
- Software configuration documentation
- Integration interface documentation
- Test plans and results
- Operation and maintenance manuals
- Warranty information and service contacts

## 9. Ongoing Support and Maintenance

### 9.1 Preventive Maintenance

- Quarterly system health checks and inspections
- Camera cleaning and alignment
- Door hardware lubrication and adjustment
- Software updates and security patches
- Database optimization and maintenance
- System performance monitoring and reporting

### 9.2 Technical Support

- 24/7 helpdesk support
- Remote diagnostics and troubleshooting
- On-site service calls (with defined response times)
- Emergency repair services
- Spare parts inventory management

### 9.3 System Upgrades and Expansion

- Firmware and software upgrade services
- Hardware refresh and replacement
- System capacity expansion
- Technology roadmap planning and consultation

## 10. Compliance and Standards

All services will be performed in accordance with applicable industry standards and regulations, including but not limited to:

- ASIS International standards for physical security
- National Fire Protection Association (NFPA) codes
- National Electrical Code (NEC)
- Americans with Disabilities Act (ADA) requirements
- Local building and electrical codes
- Data privacy regulations (GDPR, CCPA, etc.)
- Industry-specific compliance requirements (HIPAA, PCI-DSS, etc.)

## 11. Exclusions

The following items are not included in this scope of services unless specifically agreed upon in writing:

- Structural modifications to buildings or facilities
- Electrical power circuits beyond connection points
- Network infrastructure beyond security system requirements
- Security guard services or personnel
- Security policies and procedures development
- Penetration testing or vulnerability assessments
- Third-party licensing or subscription fees beyond initial period

## 12. Assumptions

This scope of services is based on the following assumptions:

- Client will provide timely access to all areas requiring equipment installation
- Adequate electrical power and network infrastructure are available at installation locations
- Client will designate a project liaison for coordination and decision-making
- All necessary permits and approvals will be obtained by the client
- Existing facility conditions are as represented in provided documentation
- No hazardous materials or adverse environmental conditions exist at installation sites
