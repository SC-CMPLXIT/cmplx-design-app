## SCOPE OF SERVICES

**Physical Security Design**

Access Control & Video Surveillance

## 1. Executive Summary

This document defines the design scope for physical security systems, including access control and video surveillance. The work produces the drawings, specifications, and equipment requirements that installation follows. It does not include mounting hardware, software configuration, commissioning, training, or maintenance.

## 2. Objectives

- Define an integrated access control and video surveillance design
- Set security zones, door hardware requirements, and camera coverage
- State network, power, and pathway requirements for the security systems
- Document retention, alerting, and integration requirements
- Give the client a specification set that can be bid and installed

## 3. Access Control Design

- Site survey and security assessment
- Door and access point identification
- Security zone definition and classification
- Access control topology design
- Network infrastructure requirements analysis
- System architecture and integration planning
- Credential, schedule, and access-level requirements

## 4. Video Surveillance Design

- Coverage analysis and camera placement planning
- Field of view calculations and lens selection
- Lighting assessment and supplemental lighting requirements
- Storage capacity requirements and retention policy design
- Network bandwidth analysis
- Video management system architecture design
- Monitoring and viewing requirements, including control room and remote viewing

## 5. Integration Requirements

- Access control and video surveillance integration requirements
- Requirements for intrusion detection, building management, and fire alarm interfaces
- Event correlation, bookmarking, and notification requirements

## 6. Design Documentation

- System design documentation and specifications
- Network topology diagrams
- Floor plans with device locations
- Equipment schedules and infrastructure requirements
- Door elevations and camera placement drawings

## 7. Exclusions

- Installation, mounting, aiming, or termination of security hardware
- Software installation, database setup, and credential enrollment
- Testing, commissioning, training, and as-built documentation
- Ongoing maintenance, helpdesk, and system upgrades
- Structural modifications to buildings or facilities
- Electrical power circuits beyond the design requirements
- Network infrastructure beyond the security system requirements
- Security guard services or personnel
- Security policies and procedures writing
- Penetration testing or vulnerability assessments
- Third-party licensing or subscription fees

## 8. Assumptions

- The client provides timely access for the survey and current floor plans
- Existing facility conditions match the documents provided
- The client designates a project liaison for coordination and decisions
- Permits and approvals for installation are outside this design scope
